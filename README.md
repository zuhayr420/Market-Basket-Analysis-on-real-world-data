Description:
This project implements Market Basket Analysis on real-world grocery transaction data using Python.
The Apriori algorithm is used to identify frequently purchased item combinations and generate association rules.

Technologies Used:
* Python
* Pandas
* MLxtend
* Apriori Algorithm

Features:
* Reads grocery transaction data
* Performs transaction encoding
* Finds frequent itemsets
* Generates association rules
* Calculates support, confidence, and lift

Dataset:
The project uses grocery transaction data containing products purchased by customers.

How to Run:
1. Clone the repository.
2. Install the required libraries
3. Place groceries.csv in the project folder
4. Run

Output

The program displays:
* Frequent itemsets
* Association rules
* Support
* Confidence
* Lift

Result

Market Basket Analysis was successfully implemented using Python to discover relationships between products in grocery transactions.
